# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。交单前必须先在「电缆截面」页把组串绑到电缆截面：没绑、或该截面允许载流低于短路电流的组串**不许入队**，整笔退回挡回样例。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 电缆截面规则

- **先绑截面再入队**：交单时按组串编号查当前绑定；没绑或载流 < 短路电流，整笔退回（不写队列），返回大白话原因并记入「挡回样例」。
- **载流随单冻结**：通过校验的单子把截面编号和当时载流快照进 `iv_scans`；事后改册子只影响新单，旧单载流不动。
- **并发只准一份**：`cable_bindings` 对电缆和组串各有唯一约束，绑同一截面时先锁电缆行再判重，两人抢绑只有一人成功，另一人收到 409 人话提示。
- **权限**：观察员（watcher）能翻载流册、队列和挡回样例，但不能登记/改册、绑串、交新单（403）。

## 顶栏页面

- **扫描台**：交单表单 + 队列（含「绑定截面 / 随单载流」两列）。
- **电缆截面**：上格「载流册」（空态显示“还没有电缆”，可登记/改载流）、中格「绑串」、下格「挡回样例」。

## 验收走查（甲串场景）

1. 登记截面 `YJV-4` 载流 12A，绑给「阵列A-串01」；
2. 交短路电流 9A 的单 → 载流 12 ≥ 9，进队列，单子上冻结 `YJV-4 / 12A`；
3. 在载流册把该截面改成 8A（旧单仍显示 12A）；
4. 再交短路电流 9A 的单 → 整笔退回：「截面YJV-4允许载流只有8A，扛不住这串9A的短路电流，换更粗的电缆绑好再来」，挡回样例新增一条，队列不增单。
