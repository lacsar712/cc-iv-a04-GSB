# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。交单前组串必须先绑上一份载流够的电缆截面：没绑截面、或截面载流低于短路电流，整笔退回，扫描单不留行，只在挡回台账上留一笔人话记录。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 电缆截面规则

- 顶栏「电缆截面」进专页，三格：上格登记/改册截面载流，中格绑串/解绑，下格看挡回样例；空台账显示「还没有电缆」。
- 先绑截面再入队。一份截面只准绑一串，一串也只准被一份截面绑；两人同时抢同一截面编号，数据库原子认绑，只准一份成功。
- 载流随单冻结：交单时把截面编号和当时载流抄进扫描单；事后改册只影响以后的单，旧单载流动不了。
- 观察员（watcher）能翻所有册（扫描单、截面、挡回样例），但不能登记/改册、不能绑串解绑、不能交新单。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/cables` | 截面台账（登录可看） |
| POST | `/api/cables` | 登记截面编号与载流（扫描员） |
| PATCH | `/api/cables/{编号}` | 改册载流，不碰旧单（扫描员） |
| POST | `/api/cables/{编号}/binding` | 原子绑串，并发只准一份（扫描员） |
| DELETE | `/api/cables/{编号}/binding` | 解绑（扫描员） |
| GET | `/api/rejections` | 挡回样例台账（登录可看） |
| GET/POST | `/api/logs` | 扫描单；交单时校验绑定与载流，不过整笔退回（POST 扫描员） |
